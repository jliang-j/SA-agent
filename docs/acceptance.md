- 未修改模型配置，未重新导入文档，未进行性能优化。

该阶段普通回归：`142 passed, 6 deselected`，不是当前代码的测试总数。

## 复现

```powershell
uv run pytest -m "not integration"
uv run pytest tests/test_real_agent_api.py -m integration -v -s
```

第二条命令调用真实模型并消耗额度。需先导入两份示例资料；资料库不存在或为空时跳过。
资料不足案例以当前两份示例资料为前提，扩充来源后可能跳过，届时需重新选择负例。

完整响应保存副本：

- `outputs/acceptance_supported.json`
- `outputs/acceptance_missing.json`

测试每次仍保存到独立临时目录并输出路径，不自动覆盖上述副本。
